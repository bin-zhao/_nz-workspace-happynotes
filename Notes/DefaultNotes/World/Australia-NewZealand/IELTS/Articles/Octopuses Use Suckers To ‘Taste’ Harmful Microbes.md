And so in that way, they’ve always been an <span style="color:rgb(255, 0, 0)">attractive</span> model.

FLORA LICHTMAN: Attractive model isn’t making my heart sing. Exactly. You have over 100 species in your lab. What animal is really capturing your heart right now?

NICHOLAS BELLONO: Maybe my favorite animal of all time– and I don’t want to say– we have a lot of great projects. I like everyone’s stuff– but maybe my personal favorite animal is the so-called <span style="color:rgb(255, 0, 0)">photosynthetic</span> sea <span style="color:rgb(255, 0, 0)">slug</span>, which I think is just totally nuts. They eat <span style="color:rgb(255, 0, 0)">algae</span>, and then they <span style="color:rgb(255, 0, 0)">suck out</span> the <span style="color:rgb(255, 0, 0)">chloroplasts</span>. And they retain them in their own bodies to do <span style="color:rgb(255, 0, 0)">photosynthesis</span>, which–

FLORA LICHTMAN: What?

NICHOLAS BELLONO: Is very weird. And then they’ll eventually digest these chloroplasts once they’re <span style="color:rgb(255, 0, 0)">severely</span> <span style="color:rgb(255, 0, 0)">starved</span>, and then they can resist <span style="color:rgb(255, 0, 0)">starvation</span> for an <span style="color:rgb(255, 0, 0)">incredibly</span> long period. It’s something that we’ve just published a new study about and how they do this. How can they retain these chloroplasts? Because the question is if the chloroplast is removed from its natural <span style="color:rgb(255, 0, 0)">habitat</span>, which is the <span style="color:rgb(255, 0, 0)">algal</span> or plant cell, how does it get new proteins? How does it keep functioning? How does the slug do that because it’s now in a slug cell?

And what we found is that the slug actually has this <span style="color:rgb(255, 0, 0)">organelle</span> it makes that takes up the chloroplast like a <span style="color:rgb(255, 0, 0)">endosymbiosis</span> like how <span style="color:rgb(255, 0, 0)">mitochondria</span> are. Mitochondria formed a really long time ago from an ancient <span style="color:rgb(255, 0, 0)">prokaryotic</span> cell. But the slug managed to do this in one lifetime. It takes in the chloroplast, it houses it in this organelle, it <span style="color:rgb(255, 0, 0)">sustains</span> it to do photosynthesis, and then once it’s really hungry, it digests the chloroplast and gets an extra boost of energy.
